# ChatGPT-style UI clone

A modern ChatGPT-inspired chat application built with Next.js, Tailwind CSS, and OpenAI-compatible API support.

## Features

- ChatGPT-style dark interface
- Sidebar with history and chat management
- Message composer with suggestions
- Markdown rendering with code blocks
- Local persistent conversation state
- Real AI responses via OpenAI API
- Responsive layout for desktop and smaller screens

## Tech stack

- Next.js 14
- React + TypeScript
- Tailwind CSS
- Lucide icons
- OpenAI SDK

## Quick start

1. Install dependencies:
   npm install

2. Add your API key:
   create a `.env.local` file and add:
   OPENAI_API_KEY=your_openai_key_here

3. Start the app:
   npm run dev

4. Open:
   http://localhost:3000

## Notes

- This project is intentionally a ChatGPT-inspired interface and not an exact copy of OpenAI’s proprietary product.
- The app expects a valid OpenAI key to generate real responses.
