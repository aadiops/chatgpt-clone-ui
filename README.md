# chatgpt-ui-clone

A ChatGPT-inspired UI prototype built with Next.js and Tailwind CSS.

## Features

- Sidebar chat history
- Main conversation pane
- Markdown rendering with code blocks
- Message composer with action buttons
- Responsive mobile layout
- Dark mode ChatGPT-inspired visual style
- Mock assistant behavior for UI demo

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

This is a frontend-only clone created to match the ChatGPT interface and UX style. It does not include proprietary backend logic or official OpenAI services.
